## Citações-chave para provas

**Sobre validação de formulários (Robbins, 2022, p. 203):** a validação HTML5 dá feedback imediato ao usuário e reduz erros de submissão, mas precisa sempre ser complementada por validação no servidor para garantir segurança.

**Sobre o protocolo HTTP (Tanenbaum & Wetherall, 2021):** o HTTP é *stateless* — cada requisição é independente das demais.

**Sobre organização de projeto (Duckett, 2014, p. 15):** uma estrutura bem organizada é o que separa um projeto que escala de um que se torna inviável.

## Ponto de reflexão da unidade

> **O futuro do front-end.** Como tecnologias emergentes — WebAssembly, Progressive Web Apps, Web Components — podem transformar o desenvolvimento front-end? E como os fundamentos estudados hoje permanecerão relevantes nesse futuro?

A conclusão da unidade: as **tecnologias de superfície** mudam rápido, mas os princípios subjacentes — comunicação web segura, estruturação de conteúdo, acessibilidade — permanecem cruciais. WebAssembly, PWAs e Web Components rodam *sobre* HTTP, sobre o DOM e sobre a semântica HTML; não os substituem. Base sólida é justamente o que permite adaptar-se às novas tendências.
