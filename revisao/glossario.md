# Glossário

## Siglas

| Sigla | Significado | O que é |
|-------|-------------|---------|
| **HTML** | HyperText Markup Language | linguagem de marcação que estrutura o conteúdo web |
| **CSS** | Cascading Style Sheets | linguagem de estilo, responsável pela apresentação visual |
| **JS** | JavaScript | linguagem de programação do navegador, dá comportamento à página |
| **HTTP** | HyperText Transfer Protocol | protocolo de comunicação da web, *stateless* |
| **HTTPS** | HTTP Secure | HTTP com criptografia via TLS |
| **TLS** | Transport Layer Security | protocolo de criptografia que protege a comunicação |
| **URL** | Uniform Resource Locator | endereço completo de um recurso na web |
| **DNS** | Domain Name System | traduz nomes de domínio em endereços IP |
| **DOM** | Document Object Model | representação em árvore do documento, manipulável por JS |
| **SEO** | Search Engine Optimization | otimização para mecanismos de busca |
| **WCAG** | Web Content Accessibility Guidelines | diretrizes internacionais de acessibilidade |
| **UX** | User Experience | experiência do usuário |
| **UI** | User Interface | interface do usuário |
| **API** | Application Programming Interface | interface de comunicação entre sistemas |
| **W3C** | World Wide Web Consortium | organismo que padroniza as tecnologias da web |
| **PBL** | Project Based Learning | metodologia de aprendizagem por projetos |
| **PWA** | Progressive Web App | aplicação web com capacidades de app nativo |
| **AJAX** | Asynchronous JavaScript and XML | requisições assíncronas sem recarregar a página |
| **CORS** | Cross-Origin Resource Sharing | política de compartilhamento entre origens diferentes |
| **IDE** | Integrated Development Environment | ambiente integrado de desenvolvimento |

---

## Termos

**Atributo** — informação extra na tag de abertura, no formato `nome="valor"`.

**Bitmap** — imagem formada por pixels; perde qualidade ao ampliar. É como o Canvas funciona.

**Boilerplate** — estrutura base obrigatória que todo documento HTML5 repete.

**Breakpoint** — largura de tela em que o layout muda de comportamento, no design responsivo.

**Canvas** — elemento HTML5 para desenho bitmap via JavaScript. Ideal para gráficos dinâmicos e alta performance.

**Elemento void (auto-fechado)** — tag que não carrega conteúdo e dispensa fechamento: `<br>`, `<img>`, `<hr>`, `<meta>`, `<link>`.

**Emmet** — sistema de abreviações do VS Code que expande atalhos em HTML completo.

**Favicon** — ícone exibido na aba do navegador.

**Lazy loading** — carregamento adiado de mídia que ainda não apareceu na tela, para acelerar o carregamento inicial.

**Marcação semântica** — uso de tags que comunicam o *significado* do conteúdo, não apenas sua aparência.

**Mobile-first** — estratégia de projetar primeiro para telas pequenas e depois ampliar.

**Nameserver** — servidor DNS responsável por responder pelas consultas de um domínio.

**Propagação DNS** — tempo até que a mudança nos registros DNS seja reconhecida globalmente.

**Query string** — parâmetros enviados na URL após `?`, no formato `chave=valor`.

**Regex (expressão regular)** — padrão de texto usado para validar formatos, como no atributo `pattern`.

**Responsividade** — capacidade do layout de se adaptar a diferentes tamanhos de tela.

**Server-side / client-side** — o que roda no servidor × o que roda no navegador do usuário.

**Stateless** — característica do HTTP: cada requisição é independente, sem memória das anteriores.

**SVG** — Scalable Vector Graphics; gráficos vetoriais em XML, escaláveis sem perda e interativos por elemento.

**Tag** — etiqueta que delimita um elemento HTML, entre `<` e `>`.

**Tecnologia assistiva** — recursos usados por pessoas com deficiência, como leitores de tela.

**Viewport** — área visível da página no dispositivo; configurada pela meta tag de mesmo nome.

**WebAssembly** — formato binário que permite rodar código de alto desempenho no navegador.

**Web Components** — padrão para criar elementos HTML customizados e reutilizáveis.
